QuickPaste Privacy Policy

How QuickPaste protects your privacy and handles your files

✓ Zero Data Collection ✓ 100% Local Processing ✓ Open Source

🛡️ Privacy Commitment

At QuickPaste, your privacy is our top priority. QuickPaste operates 100% locally within your browser. We do not collect, store, transmit, rent, or sell any personal data, browsing history, clipboard content, or uploaded files.

📂 File & Clipboard Handling

QuickPaste is designed solely to help you upload files faster by pasting (Ctrl+V) or dragging and dropping them into standard file upload fields (<input type="file">).

  • When you paste or drop a file, it is passed directly in browser memory to the file input element of the website you are actively using.
  • QuickPaste never reads, saves, or uploads your files or clipboard data to any external server.
  • No file data or metadata is ever persisted by the extension after the action completes.

🔒 Zero Data Collection & No Tracking

QuickPaste strictly adheres to a zero-telemetry policy:

  • No External Servers: The extension makes zero network requests to external APIs or servers.
  • No Analytics or Tracking: We do not use Google Analytics, tracking pixels, fingerprinting, or any third-party telemetry scripts.
  • No Cookies or Storage: QuickPaste does not use cookies or store any personal data.

🔑 Permissions Justification

QuickPaste requests the minimum permissions necessary to function:

  • Host Permissions (<all_urls> / Content Scripts): Required solely to detect <input type="file"> fields on the web pages you visit and attach the local paste/drop interface when you click a file input.

QuickPaste does not read or monitor any other page content, form inputs, or browsing activity.

💻 Open Source Transparency

QuickPaste is completely open source. Anyone can inspect our source code on GitHub to verify that no user data is collected or transmitted outside your browser.

📬 Contact

If you have any questions regarding this Privacy Policy, please reach out by opening an issue on our GitHub Repository.
